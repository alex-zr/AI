# Строка — последовательность

У строки есть длина и порядок элементов. Индекс обращается к одной позиции.

```python
text = "Кот"
print(len(text))
print(text[0], text[-1])
```

Вывод:

```text
3
К т
```

Позиции: `0 → К`, `1 → о`, `2 → т`; `-1` — последний элемент.

<!-- S02-M06-SL004 -->
# Кодовая точка — не экранный знак

`len(str)` считает кодовые точки Unicode. Отрисовка может объединить несколько кодовых точек в один видимый знак.

```python
text = "e\u0301"
print(len(text))
print(text[0] == "e", text[1] == "\u0301")
```

Вывод:

```text
2
True True
```

**Следствие:** индекс и `len()` не считают пользовательские графемные кластеры. Вид глифа зависит от отображения.

# Индекс требует границы

- Для непустой строки последний элемент: `text[-1]`.
- Положительный индекс последнего элемента: `len(text) - 1`.
- Для пустой строки сначала проверьте `if text:`.
- `text[len(text)]` — за границей и вызывает `IndexError`.

Строка неизменяема: получить элемент можно, заменить через `text[0] = ...` нельзя.

# Срез выбирает диапазон

Форма: `text[start:stop:step]`.

```python
text = "abcdef"
print(text[1:4])
print(text[:3] + text[3:])
```

Вывод:

```text
bcd
abcdef
```

`stop` не включается: первый срез берёт позиции `1, 2, 3`. Соседние части на границе `3` стыкуются обратно.

# Шаг определяет направление

```python
text = "abcdef"
print(text[::2])
print(text[4:1:-1])
print(text[::-1])
```

Вывод:

```text
ace
edc
fedcba
```

При отрицательном шаге идём к меньшим индексам. Пропущенная граница и явно записанный `-1` — не одно и то же.

# Текст и байты — разные типы

- `str` — текстовая последовательность Unicode.
- `bytes` — последовательность значений-байтов от 0 до 255.
- Unicode описывает текст; UTF-8 — способ записать текст байтами.

```python
text = "AЯ😀"
data = text.encode("utf-8")
print(len(text), len(data))
```

Вывод: `3 7`.

<!-- Заметки докладчика: длина str считает кодовые точки; длина bytes — байты. Стандартный тип языка Python 3.14; конкретное внутреннее хранение реализации не обсуждается. -->

<!-- S02-M06-SL028 -->
# Кодирование и декодирование

```python
text = "AЯ😀"
data = text.encode("utf-8")
print(data)
print(data.decode("utf-8") == text)
```

Вывод:

```text
b'A\xd0\xaf\xf0\x9f\x98\x80'
True
```

Направления: `str.encode(encoding) → bytes`; `bytes.decode(encoding) → str`.
