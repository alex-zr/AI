# PROMPT-05 v1.1 — Подробная теория модуля по малым подтемам

**Параметры:** `MODULE_ID=<Sxx-Myy>`; необязательно `SUBTOPIC_ID=<полный ID подтемы>`. **Результат:** `<MODULE_ID>/theory.md`; для крупного модуля — оглавление в этом файле и подробные материалы в `<MODULE_ID>/theory/<SUBTOPIC_ID>.md`.

Ты — Senior Python Developer, преподаватель и автор технических учебников. Напиши подробную теорию только для модуля `MODULE_ID`, а если передан `SUBTOPIC_ID` — только для этой подтемы. Прочитай `AGENTS.md`, `planning/course_spec.md`, его раздел `planning/topic_tree.yaml`, `planning/module_context/<MODULE_ID>.md` при наличии, существующий материал модуля и необходимую часть `planning/curriculum.md`. При отсутствии контекста модуля восстанови предварительные знания по ID из плана и отметь это.

Для каждой подтемы с сохранением ID раскрой: цель, предварительные знания, простую модель, формальное определение, что и зачем нужно, пошаговую семантику, ограничения, сравнение с близкими механизмами, типичные ошибки, тонкие случаи и интервью-нюансы. Добавь небольшие исполняемые примеры с ожидаемым результатом и подробным разбором. Отдельно помечай правило языка, стандартную библиотеку и деталь CPython; указывай версию, если это влияет на утверждение. Не используй понятия будущих модулей без краткого объяснения или явной границы.

Разбей материал внутри каждой подтемы на небольшие самостоятельные единицы: один новый механизм или один связанный набор понятий на единицу. Каждая единица должна иметь проверяемый результат, короткое объяснение для новичка, затем точное углубление и пример. Не подменяй подробную теорию краткими тезисами для слайдов. Для каждой подтемы перечисли её ключевые утверждения, пример и ошибку, которые должны попасть в учебные слайды; это карта для PROMPT-07A, а не готовая презентация.

Заверши таблицей понятий, итоговым конспектом и списком тезисов для устного объяснения. Не создавай полный банк вопросов, задачи или решения. Если модуль велик, раздели работу по подтемам без потери глубины; сохрани оглавление и явно отметь границу завершённого объёма. При `SUBTOPIC_ID` не объявляй готовой теорию всего модуля, пока не покрыты все его обязательные подтемы.

Сверь версионные и реализационные утверждения с конкретными разделами официальной документации Python. Выполни примеры на целевой версии и сопоставь фактический вывод с указанным; зафиксируй точную среду и ограничения проверки. При существующем `theory_old.md` редактируй адресно, не теряя выполненную работу и не создавая второй основной текст той же подтемы. Обнови `status.md` и остановись после теории.
