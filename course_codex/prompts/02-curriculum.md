# PROMPT-02 v1.1 — Каркас полной программы

**Выполнять:** после спецификации. **Результат:** `planning/curriculum.md`, `planning/topic_tree.yaml`, `planning/coverage_report.md`.

Ты — архитектор образовательной программы Core Python. Прочитай `AGENTS.md`, `planning/course_spec.md`, `planning/initial_modules.md` и существующие файлы плана. Используй исходные 24 модуля как основу. Добавление, разделение, объединение и изменение порядка модулей допустимы только с явным обоснованием и картой соответствия исходным модулям.

Построй иерархию этап → модуль → тема → подтема → учебный результат. Для каждой подтемы укажи стабильный уникальный ID, название, понятия, результат, глубину, экспертный приоритет интервью, предварительные знания по ID, плановое число теоретических вопросов и практических задач, значимость для понимания CPython, типичную ловушку и обязательное повторение в более позднем модуле, если оно нужно. Планируй подтему как небольшую самостоятельную единицу для подробной теории и короткого блока слайдов; отмечай, после каких результатов доступны простые задачи, а после каких — интеграционные задачи средней, высокой и интервью-сложности. Если плановое число задач не позволяет получить все четыре категории на модуль, отметь дефицит для отдельного решения, не меняя утверждённый план скрыто.

Проверь порядок зависимостей, отсутствие «знаний из будущего», отсутствие необоснованных дублей и покрытие синтаксиса, типов, функций, коллекций, исключений, ООП, итерации, памяти и стандартной библиотеки. В `coverage_report.md` зафиксируй пробелы и решения, а не только заявление о полноте. `curriculum.md` должен быть читаемым оглавлением, `topic_tree.yaml` — машиночитаемой иерархией с теми же ID. Дай предварительную оценку минут по трём категориям спецификации в `planning/workload.md`; если данных для точной оценки ещё нет, укажи допущения и пометь оценку как предварительную.

Если полный объём не помещается в один проход, сохрани полноценный результат для текущего этапа и явно отметь незавершённые этапы; продолжай через PROMPT-03. Не сокращай детализацию отдельной подтемы ради общего количества. Не создавай теорию, вопросы, задачи или решения.

Проверь YAML синтаксически, уникальность ID, существование ссылок на предварительные знания, согласованность файлов и покрытие всех исходных модулей. Сохрани отчёт о проверке в `coverage_report.md` и обнови `status.md`. Остановись после структуры.

**История:** v1.0 — объединены два пересекающихся запроса на учебный план из `prompts.txt`; пути согласованы с `planning/`.
