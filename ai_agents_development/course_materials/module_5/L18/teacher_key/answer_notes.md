# L18. Закрытые ориентиры преподавателя

Граница практики — 5. Для 4 вывод «мало», для 5 — «достаточно». Проверить не только наличие if/else, но и точный смысл сравнения. Ошибку > вместо >= выявляет случай 5. Демонстрация с порогом 10 находится в demo.py, эталон практики — reference.py.

## Вопросы с ожидаемыми ответами

- Когда исполняется else? → Когда условие if ложно
- Как проверить >=? → Включить равенство в набор входов
- Зачем проверять обе ветви? → Одна успешная ветвь не подтверждает другую.

## Проведение демонстрации

Из каталога teacher_key запустите demo.py и demo_bad.py сначала со значением 9. Затем в одноразовых копиях замените первую строку на amount = 10. Ожидание для правильного варианта: «ожидание», затем «доступ». Ошибочный вариант при 10 оставляет «ожидание».

Команда сверки демонстраций и эталона из teacher_key: `python3 -B test_outputs.py -v`.
