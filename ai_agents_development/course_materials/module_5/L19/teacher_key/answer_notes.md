# L19. Закрытые ориентиры преподавателя

Для n = 0 проверять пустую строку, а не наличие слова «шаг». Нормальный случай n = 3 даёт три строки. range(n + 1) ломает оба случая. Тесты не зависят от имени переменной, если смысл сохранён.

## Вопросы с ожидаемыми ответами

- Сколько раз выполнится range(0)? → Ноль
- Включается ли верхняя граница range(n)? → Нет
- Как обнаружить лишнюю итерацию? → Сравнить точный вывод при нуле и при положительном n.

Из каталога teacher_key запустите demo.py и demo_bad.py сначала с n = 2. Затем в одноразовых копиях задайте n = 0. Правильный вариант печатает две строки и ни одной соответственно. Ошибочный печатает три и одну.
