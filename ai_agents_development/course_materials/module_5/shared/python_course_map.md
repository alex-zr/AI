# Учебная граница Junior и шаблон карты Python

Организатор подтверждает профиль до L17. Минимальный охват: первые программы, переменные, условия, циклы, функции, небольшой проект и его проверка. На выходе ученик читает и меняет короткую программу, реализует функцию по условию, проверяет обычный и пограничный случаи и объясняет решение. Навыки запуска и проверки вводятся до зависимых задач. «Переменные», «Условия» и «Циклы» — три разрабатываемых урока. Первые программы, функции и проект тоже входят в карту.

| ID темы | Тема | Наблюдаемый результат ученика | ID ранее введённых предпосылок | Практика | Как проверяется | Ссылка на готовый урок или статус |
|---|---|---|---|---|---|---|
| | | | | | | |

Проверка карты: покройте все темы и результаты профиля. Каждая предпосылка либо указана на входе курса, либо имеет ID более ранней строки. В каждой строке сверьте, что практика вызывает заявленное действие, а проверка его наблюдает. Этот профиль описывает будущего ученика Python. Навыки работы с агентами оцениваются отдельно.
