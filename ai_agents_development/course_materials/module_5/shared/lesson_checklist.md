# Чек-лист готового урока

Заполните отдельно для каждого из трёх уроков. На L18–L19 отмечайте недостающее и следующий шаг. На L20 для каждого выполненного пункта приложите путь, строку или свидетельство запуска.

| Проверка | Статус и свидетельство |
|---|---|
| Место в карте, аудитория, длительность, предпосылки и 2–4 наблюдаемых результата | |
| Объяснение и не менее двух исполняемых примеров | |
| Задание на закрепление и задание на перенос, с входами и критериями самопроверки | |
| Для каждого действия указано, где ученик освоил нужный навык | |
| Минимум три вопроса для собеседования, элементы ответов доступны преподавателю | |
| Типичная ошибка и способ её обнаружить | |
| Условие, ожидаемое поведение, эталон и закрытая проверка согласованы | |
| Все обязательные примеры запущены. Свидетельства связаны со снимком | |

Отделяйте учебную версию от закрытых ответов. [Требования проекта](../../../agentic_development_course_final.md#project).
