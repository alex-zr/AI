# Циклы

Место: PY04. Аудитория: начинающие. Длительность: 20 минут. Предпосылки: PY01–PY02: запуск, вывод и чтение переменной. range вводится здесь.

## Результаты ученика

- Предсказать число строк при положительном n
- Объяснить отсутствие вывода при нуле.

## Объяснение

range(n) даёт n значений при неотрицательном n, начиная с 0. print внутри цикла выполняется по одному разу на значение. При нуле тело пропускается.

## Примеры

[Первый](example_1.py) и [второй](example_2.py). Перед каждым запуском запишите прогноз, затем сверьте фактический вывод.

## Закрепление и перенос

1. В первом примере задайте n = 2. Сравните прогноз числа строк с фактическим выводом.
2. Замените слово «шаг» на «точка» и проверьте n = 0 и n = 4. Сверьте количество и текст каждой строки.

## Вопросы для собеседования

- Сколько значений даёт range(0)?
- Входит ли n в range(n)?
- Почему range(n + 1) печатает лишнюю строку?

## Типичная ошибка

Лишняя итерация. Сравните точное число строк, включая нулевой случай.
