# Резервный комплект L20

Используйте при недоступности артефактов L16–L19. Сверьте карту и три черновика. В комплекте есть один учебный разрыв в предпосылках. По карточке выберите его для сравнения и доработайте комплект. Каждый example_1.py и example_2.py запускается отдельно из каталога темы с Python 3.
