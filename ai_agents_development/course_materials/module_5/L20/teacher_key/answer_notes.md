# L20. Закрытые ориентиры преподавателя

В резервном снимке у упражнения «Условия» лишняя предпосылка: собственная функция ещё не введена. Допустимая правка — дать готовый фрагмент ветвления и попросить менять значение и проверять вывод. Условия задания и эталон после исправления должны согласоваться. Невыполненные пункты не отмечаются готовыми.

## Вопросы с ожидаемыми ответами

- Как найти скрытую предпосылку? → Сопоставить каждое действие с местом ввода навыка
- Что должно быть в журнале? → Разрыв, правка и повторная проверка
- Зачем замораживать снимок? → Обе проверки ревью должны смотреть одну версию.

## Приёмка резервного комплекта

- Переменные: ожидайте «восток» в закреплении и «запад» в переносе. Вопросы: имя читается в момент print, второе присваивание меняет текущее значение, один print в этих примерах даёт одну строку.
- Условия: перепишите закрепление как изменение первой строки выданного примера. Для 4 ожидайте «мало», для 5 — «достаточно». Для порога 7 те же строки при 6 и 7 соответственно. Вопросы: else при ложном условии, >= включает равенство, для обнаружения > нужен вход на пороге.
- Циклы: ожидайте две строки «шаг», затем ноль и четыре строки «точка». Вопросы: ноль повторений, верхняя граница исключена, n + 1 даёт одно дополнительное значение.

Из каталога занятия выполните `python3 -B teacher_key/test_snapshot.py -v` для проверки шести исходных примеров. Для изменённых работ сверяйте фактические файлы участника, а не только исходный резервный снимок.
