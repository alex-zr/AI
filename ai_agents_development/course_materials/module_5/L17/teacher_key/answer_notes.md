# L17. Закрытые ориентиры преподавателя

Первые программы вводят запуск и вывод, переменные опираются на запуск, условия — на значения и сравнение, циклы — на вводный счёт и ранее изученный вывод, функции — на чтение небольшого фрагмента кода. Допустим другой порядок при соблюдении зависимостей. Практика и способ проверки нужны и для проекта. Типичная ошибка — сослаться на функцию как предпосылку для переменных, сохранив функции в конце карты.

## Вопросы с ожидаемыми ответами

- Что делает результат наблюдаемым? → Действие ученика и видимое свидетельство
- Как найти цикл без инструмента? → Сверить каждую предпосылку с порядком строк
- Зачем фиксировать границу Junior? → Проверять охват по согласованному профилю.
