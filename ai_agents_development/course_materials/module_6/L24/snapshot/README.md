# Резерв для репетиции передачи

Для репетиции выдайте одну и ту же копию этих файлов. Выполните шаг из handoff.md и проверьте его вручную по критериям. Этот снимок отрабатывает только процедуру передачи. Итоговый выпуск, оценки и повторный запуск общей команды предъявляются на собственном проекте.
