# Мини-пример локальной проверки

Скрипт `example.py` должен печатать «мало» для 4 и «достаточно» для 5. Текущая первая строка задаёт 5. Для ручной сверки используйте одноразовую копию и измените только значение первой строки. Преподаватель предоставляет способ запуска закрытой проверки и контрольную копию отдельно. Этот мини-пример отрабатывает запуск и диагностику, полная приёмка курса выполняется на собственном комплекте.
