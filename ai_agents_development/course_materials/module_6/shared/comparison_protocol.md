# Протокол OpenCode и Codex для L21–L24

1. Зафиксируйте исходную версию, список файлов, один запрос, разрешённую область, критерии, порядок и общий лимит. Для L21 выберите чтение без правок. Для L22 передайте публичный перечень входов, закрытый комплект храните вне агентских копий. Для L23–L24 ограничьте правку одним файлом.
2. Создайте две чистые копии и два свежих сеанса. Сравниваемый фактор — среда. В обоих сеансах используйте один снимок, задачу, критерии и время. Если настройки, модель или разрешения отличаются, запишите это и ограничьте вывод.
3. Сохраните исходный ответ, diff, время и результат или сбой. Зафиксируйте ручные изменения отдельно. На L23 одинаково проверьте обычный и пограничный случаи. На L24 повторите общую проверку на выбранном варианте.
4. Если запуск недоступен, запишите «нет данных». Сохранённый или симулированный пример годится для разбора, отмечайте его происхождение. При сбое сохраните исход, объясните отклонение и предъявите результат повторной проверки исправления.
