# L05. Ориентиры для преподавателя

Цель — предсказание вывода после замены строки. Входы — заявка и сведения об ученике. Границы — одно присваивание, один print, без правок файлов. Приёмка — ученик видит начальную и новую строки и может точно назвать вывод. Типичный дефект: «измените переменную» без нового значения. Проверка: вывести значение по инструкции вручную, сверить с текстом и отдельно записать исправление.

Сверьте сохранённые исходы и ручные правки отдельно. Используйте [рубрику](../../assessment.md) и критерии [карточки](../practice_card.md). Привяжите оценку к конкретному фрагменту, артефакту или результату проверки.
