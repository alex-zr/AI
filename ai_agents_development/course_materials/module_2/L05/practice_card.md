# Практика L05. Контракт задачи

**Аудитория:** участники курса агентной разработки. **Предпосылки:** L04: одинаковые входы, отдельные попытки, diff и журнал.

**Общий вход:** файлы из [snapshot](snapshot/), один и тот же стартовый снимок для OpenCode и Codex. Временные файлы и записи держите вне исходного снимка. Эталоны преподавателя не входят в контекст.

## Задание

Уточните расплывчатую заявку на упражнение по переменным. Соберите запрос из двух файлов снимка. Получите только текст упражнения с помощью обеих сред. Ответ должен позволить новичку предсказать вывод после замены значения.

1. Запишите начальный снимок, порядок и лимиты. Начните каждую попытку в свежем сеансе и отдельной копии. Следуйте [протоколу](../shared/comparison_protocol.md).
2. Сохраните исходные ответы либо признаки сбоя. Сверьте область правок. Проверьте результат по критериям ниже.
3. При необходимости исправьте результат отдельно и повторите нужную проверку. Сохраните [журнал](../shared/run_journal.md). Отделите вывод по фактическим попыткам от гипотезы.

**Время:** 10 разбор входов + 15 контракт + 24 две попытки по 12 + 16 проверка и исправление + 10 журнал = 75 минут.

**Критерии:** Запрос содержит все четыре части контракта. В ответе есть исходное и новое значение, одно присваивание, один вызов print, инструкция предсказания и запуска, а ожидаемый вывод определим. Снимок не изменён.

**Сдача:** Запрос, две записи попыток, решение по каждому ответу и исходная/исправленная версии при обнаружении отклонения. Ссылки на свидетельства добавьте в журнал. [Рубрика](../assessment.md).
