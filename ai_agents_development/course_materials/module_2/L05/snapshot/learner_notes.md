# Входные условия

Ученик уже видел присваивание и print. Используйте одну строковую переменную и один вызов print. Дайте ученику заменить исходное значение другим заданным значением, предсказать точный вывод и проверить его запуском. Возвращайте только текст упражнения. У файлов снимка режим чтения.
