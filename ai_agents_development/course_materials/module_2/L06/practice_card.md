# Практика L06. Ограничения и примеры

**Аудитория:** участники курса агентной разработки. **Предпосылки:** L05: контракт. L02–L04: запуск Python, сравнение вывода и запись изменений.

**Общий вход:** файлы из [snapshot](snapshot/), один и тот же стартовый снимок для OpenCode и Codex. Временные файлы и записи держите вне исходного снимка. Эталоны преподавателя не входят в контекст.

## Задание

Переработайте фрагмент о переменных из снимка по двум образцам подачи. Обеим средам передайте один запрос. Выполните код из обеих версий в отдельных временных файлах, предварительно убедившись, что код выполняет только показанное присваивание и вывод.

1. Запишите начальный снимок, порядок и лимиты. Начните каждую попытку в свежем сеансе и отдельной копии. Следуйте [протоколу](../shared/comparison_protocol.md).
2. Сохраните исходные ответы либо признаки сбоя. Сверьте область правок. Проверьте результат по критериям ниже.
3. При необходимости исправьте результат отдельно и повторите нужную проверку. Сохраните [журнал](../shared/run_journal.md). Отделите вывод по фактическим попыткам от гипотезы.

**Время:** 10 разбор образцов + 12 подготовка запроса + 24 две попытки по 12 + 19 проверка текста и кода + 10 журнал = 75 минут.

**Критерии:** Сохранились три факта черновика: обращение по имени, присваивание строки, вывод Аня. Оба образца подачи распознаются, новые термины объяснены. Код запускается на Python 3, вывод совпадает с заявленным, снимок не изменён.

**Сдача:** Один запрос, две версии текста, файлы извлечённых примеров, вывод запусков, таблица проверок и выбор версии. Ссылки на свидетельства добавьте в журнал. [Рубрика](../assessment.md).
