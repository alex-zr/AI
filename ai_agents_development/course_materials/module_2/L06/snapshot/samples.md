# Два образца подачи

1. Сначала простое объяснение одним предложением, затем действие ученика.
2. Сначала попросите предсказать вывод короткого примера, затем дайте способ сверить ответ.

Образцы задают подачу. Имена и значения берите из черновика. Текст — до 120 слов без учёта кода. Не используйте новые термины без пояснения.
