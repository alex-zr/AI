# Проверка комплекта модуля 2

Входы — утверждённая программа L05–L08, правила проекта и структура модуля 1. Снимки небольшие, с одинаковой предметной задачей для обеих сред. В L08 вариант B добавляет одну инструкцию о сверке. Все четыре попытки сохраняются в матрице.

| Проверка | Результат |
|---|---|
| Планы и карточки L05–L08 | По 75 минут объяснения и практики, всего 600 минут. Для каждой практики указаны критерии и сдаваемые свидетельства. |
| Входные файлы и ссылки | У каждого занятия есть снимок. Локальные ссылки и явные якоря разрешаются. Карточки и снимки не ссылаются на закрытые эталоны. |
| L08 | Разбивка 5 + 32 + 28 + 10. Сверка текстов подтвердила, что B отличается от A одной добавленной строкой. |
| Python L06 | Локально прошли два теста стандартной библиотеки. Демонстрационный запуск вывел «кот». |
| Запуски в OpenCode, Codex и CI | Не проводились. |

Воспроизведение локальной проверки L06 из корня:

```sh
python3 -B -m unittest discover -s course_materials/module_2/L06/teacher_key -v
python3 -B course_materials/module_2/L06/teacher_key/demo_examples.py
```

До проведения преподавателю нужны доступ к обеим средам, настройки разрешений, чистые копии снимков и сохранённые примеры для разбора при сбое. Пилот должен подтвердить длительность попыток и ручных проверок на целевой аудитории.
