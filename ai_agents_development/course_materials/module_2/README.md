# Модуль 2. Prompt Engineering

Вход — опыт L01–L04: рабочая копия, чтение diff, запуск короткого примера, первая парная проверка. Модуль занимает 4 × 150 минут (10 часов): 5 часов объяснения и демонстрации, 5 часов практики. Источник — [утверждённая программа](../../agentic_development_course_final.md#lessons).

| Занятие | Результат для проекта | Материалы |
|---|---|---|
| L05. Контракт задачи | Запрос и проверяемое решение о приёмке | [План](L05/lesson_plan.md) · [Практика](L05/practice_card.md) |
| L06. Ограничения и примеры | Запрос с границами и образцами, две версии текста | [План](L06/lesson_plan.md) · [Практика](L06/practice_card.md) |
| L07. Декомпозиция | План из 3–5 шагов и проверенный первый выход | [План](L07/lesson_plan.md) · [Практика](L07/practice_card.md) |
| L08. Оценка промптов | Матрица четырёх попыток и обоснованный выбор | [План](L08/lesson_plan.md) · [Практика](L08/practice_card.md) |

В библиотеку промптов сохраняются проверенные запросы, условия, доказательства и ограничения вывода. Этот материал используется при отборе источников на L09. Черновики по переменным здесь служат тренировочным материалом. Готовые уроки проекта собираются позже, на L16–L20.
