## 1. Как читать статусы

| Статус | Значение |
|---|---|
| Выполнено | Есть команда и записанный результат в этом отчёте |
| Частично | Проверена только часть (например, структура без запуска примеров) |
| Не выполнено | Проверка не проводилась |
| Требует человека | Нужна независимая оценка, автоматическая проверка не даёт ответа |
| Требует среды | Нужен установленный OpenCode или Codex и пилот |
| Требует CI | Нужен настроенный CI; в ходе подготовки не настраивался |

**Важно:** OpenCode и Codex при подготовке не запускались. Все описания их ответов в главах являются учебными примерами. Фактические версии, модели, разрешения и время должны быть проверены на пилоте.

## 3. Фактические запуски Python и Git

Все команды ниже выполнялись локально 4 ноября 2026 года в отдельном временном каталоге вне репозитория. Учебные файлы не содержат полных решений в ученических папках.

### 3.1. L02: `welcome`, `shout`, `print`/`return`

Команды:

```bash
python3 run_welcome.py
python3 run_shout.py
python3 print_return.py
```

Фактический вывод:

```text
Добро пожаловать в Москва!
Добро пожаловать в Казань!
код возврата: 0
ADA!
КОТ!
код возврата: 0
Привет, Ada!
Результат print-функции: None
Результат return-функции: Привет, Ada!
код возврата: 0
```

Снимок L02 с `NotImplementedError` дал код возврата `1` и две строки `Фактически: ошибка NotImplementedError`. Реализация `return f"Привет, {name}!"` дала два совпадения и код `0`; третий вход `greet("Виктор")` напечатал `Привет, Виктор!`. Вариант с `print` внутри функции дал `Фактически: None` и код `1`.

### 3.2. L03: красный и зелёный запуск

Команда:

```bash
python3 -m unittest discover -s tests -v
```

На дефектном `greet.py`:

```text
test_inner_space ... ok
test_plain_name ... ok
test_surrounding_spaces ... FAIL
AssertionError: 'Привет,   Ada  !' != 'Привет, Ada!'
Ran 3 tests
FAILED (failures=1)
код возврата: 1
```

После `name.strip()`:

```text
Ran 3 tests
OK
код возврата: 0
```

Always-pass тест `assertTrue(True)` дал `OK` и код `0` при сохраняющемся дефекте B2 — это подтверждает, что зелёный запуск сам по себе ничего не доказывает.

Демонстрация `shout`: дефектная версия вернула `'ada!'`, версия с `upper()` — `'ADA!'`.

Команды:


Решение с `greeting="Привет"` и двумя новыми тестами дало `Ran 5 tests`, `OK`, код `0`. Вызовы `greet("Ada")` и `greet("  Ada  ", "Здравствуйте")` вернули `Привет, Ada!` и `Здравствуйте, Ada!`.
