# Модуль 4. Длительная работа с агентами

Четыре занятия по 150 минут, всего 10 часов. Модуль использует контракты из [модуля 2](../module_2/README.md) и выбор источников и правил из [модуля 3](../module_3/README.md). Порядок задан [итоговой программой](../../agentic_development_course_final.md#lessons).

| Занятие | Артефакт | Материалы |
|---|---|---|
| L13. Контрольная точка | Коммит, запись состояния и подтверждение партнёра | [План](L13/lesson_plan.md) · [Практика](L13/practice_card.md) |
| L14. Краткая спецификация | Одна страница с проверками и открытыми вопросами | [План](L14/lesson_plan.md) · [Практика](L14/practice_card.md) |
| L15. Передача задачи | Два протокола продолжения по пакету и проверки | [План](L15/lesson_plan.md) · [Практика](L15/practice_card.md) |
| L16. Пилотный урок | Проверяемый черновик «Переменные» и перечень недостающего | [План](L16/lesson_plan.md) · [Практика](L16/practice_card.md) |

L15 использует предоставленный пакет H15, чтобы все могли проверить передачу в одинаковых условиях. Спецификация L14 служит основой для сверки брифа L16. Черновик L16 переходит в L17 для сопоставления с картой Python-курса и затем дорабатывается по [требованиям проекта](../../agentic_development_course_final.md#project). Полная карта и три готовых урока остаются результатом итогового проекта.
