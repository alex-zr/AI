# Подготовка преподавателя

- До L13 проверьте Git, доступ к двум средам и возможность выдать чистые копии. Организуйте пары для проверки контрольных точек. Предусмотрите готовый учебный коммит для участника, которому нужна помощь с повторением L01.
- До L14 выдайте общие шаблоны, рубрику модуля и полный состав готового урока. В L14 отдавайте обеим средам идентичный пакет с шаблоном спецификации и критериями.
- Для L15 подготовьте Python 3 и способ запустить закрытый тест на исходной копии и обеих результатах. Убедитесь, что агенту видны только файлы учебного пакета.
- Для L16 подготовьте чистые заготовки и откройте шаблон готового урока для сверки. Договоритесь, как сохранять пример, проверку и список недостающего к L17. Прогноз и наблюдение записываются отдельно.
- Для сбоя подготовьте маркированный пример, а также время на локальную сверку. При отсутствии запуска не приписывайте инструменту наблюдения.
