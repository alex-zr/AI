# L01. Подготовка преподавателя

> МАТЕРИАЛ ПРЕПОДАВАТЕЛЯ. Не выдавать участникам.

## 1. Рабочие папки

На участника:

```text
cohort/<participant-id>/L01/
  opencode/          пустая папка
  codex/             пустая папка
  sentinel.txt       файл вне рабочих папок, для проверки границы
```

`opencode/` и `codex/` должны быть пустыми, без `.git`. Не создавайте структуру заранее: её создаёт участник.

`sentinel.txt` лежит рядом с рабочими папками, но вне их. Запишите его хеш до занятия:

```bash
shasum -a 256 cohort/<participant-id>/L01/sentinel.txt
# либо, если доступен: sha256sum cohort/<participant-id>/L01/sentinel.txt
```

После практики проверьте хеш повторно. Если он изменился, агент или участник вышел за область; это критическое событие, а не «мелкая правка».

## 2. Назначение первичной среды

До начала занятия назначьте первичную среду и запишите её. Например, чередуйте по участникам: первый — OpenCode, второй — Codex. Не меняйте назначение после просмотра результатов.

## 3. Настройки инструментов

Проверьте в установленной версии:

- как задаётся рабочая папка/workspace;
- как выглядит режим подтверждений;
- можно ли ограничить запись только рабочей папкой;
- какие команды требуют отдельного подтверждения.

Точные названия пунктов зависят от версии. Не записывайте в карточку вымышленные названия. Если настройка недоступна, участник фиксирует это в журнале.

## 4. Проверка перед занятием

- [ ] Обе среды запускаются.
- [ ] Python 3 и Git доступны в терминале.
- [ ] Рабочие папки пусты.
- [ ] `sentinel.txt` создан, хеш записан.
- [ ] Карточки `structure_card.md` и `boundary_card.md` напечатаны или доступны только для чтения.
- [ ] Форма журнала доступна.
- [ ] Эталонный скрипт `check_structure.py` запускается на подготовленном тестовом репозитории.
- [ ] В папках нет секретов и личных данных.

## 5. Демонстрационные папки

Для показа используйте отдельную одноразовую папку, например:

```bash
mkdir -p /tmp/l01-demo-<date>
cd /tmp/l01-demo-<date>
```

Не показывайте выход за область в домашнем каталоге и не используйте реальные проекты. После демонстрации удалите папку.

## 6. Быстрая проверка эталона

Создайте временный репозиторий, повторите дерево и коммит, затем запустите:

```bash
python3 teacher_key/check_structure.py /tmp/l01-reference
```

Ожидается `PASS`. Если скрипт падает на корректном дереве, исправьте скрипт до занятия, а не объясняйте сбой участникам.
