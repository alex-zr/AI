# Снимок L01

Этот снимок состоит из двух карточек и двух пустых рабочих папок, которые выдаёт преподаватель:

- `structure_card.md` — что создать;
- `boundary_card.md` — что разрешено и запрещено;
- `L01-opencode/` — пустая рабочая копия;
- `L01-codex/` — пустая рабочая копия.

Порядок работы, запрос, тайминг и формат сдачи — в [`../practice_card.md`](../practice_card.md).

Не редактируйте карточки: это входные данные задания. Все рабочие файлы создаются только в папках `L01-opencode/` и `L01-codex/`.
