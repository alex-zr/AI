# Карточка структуры L01

Создайте в каждой рабочей копии ровно такую структуру:

```text
README.md
.gitignore
notes/
  permissions.md
  session-log.md
src/
  .gitkeep
tests/
  .gitkeep
```

## Требования к файлам

### `README.md`

```text
# Модуль 1
Учебный репозиторий для L01–L04.
```

### `.gitignore`

Три строки:

```text
__pycache__/
*.pyc
.DS_Store
```

### `notes/permissions.md`

Заголовок и четыре раздела:

```text
# Журнал разрешений L01
## Область
## Разрешено
## Запрещено
## Запросы и решения
```

В разделе «Область» укажите полный путь к рабочей копии. В «Запросах и решениях» фиксируйте каждое наблюдённое событие: что запрошено, что разрешено, что отклонено.

### `notes/session-log.md`

```text
# Журнал сеанса
- Дата:
- Среда:
- Что сделано:
- Проверка:
```

### `src/.gitkeep` и `tests/.gitkeep`

Пустые файлы. Они сохраняют папки в Git.

## Коммит

Сообщение первого коммита:

```text
L01: scaffold module 1
```

## Готово, если

- дерево совпадает полностью;
- лишних файлов нет;
- `git status --porcelain` пуст;
- `git log --oneline` показывает коммит с нужным сообщением;
- в журнале разрешений есть хотя бы одно запись «запрошено → разрешено/отклонено».
