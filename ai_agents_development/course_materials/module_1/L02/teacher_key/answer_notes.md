# L02. Заметки преподавателя

> МАТЕРИАЛ ПРЕПОДАВАТЕЛЯ. Не выдавать участникам.

## Эталон функции

```python
def greet(name):
    return f"Привет, {name}!"
```

`run_greeting.py` печатает:

```text
Вход: 'Ada'
Ожидалось: 'Привет, Ada!'
Фактически: 'Привет, Ada!'
Вход: 'Борис'
Ожидалось: 'Привет, Борис!'
Фактически: 'Привет, Борис!'
```

Код возврата `0`.

Устная проверка:

```python
greet("Виктор")  # "Привет, Виктор!"
```

## Почему на L02 нет unittest

Программа вводит тесты на L03. На L02 достаточно запуска и сравнения с ожидаемым. Проверочный файл `run_greeting.py` — это протокол запуска, а не тестовый фреймворк. Не превращайте L02 в скрытое введение L03: участник должен увидеть разницу между «я запустил и сравнил» и «тест автоматически проверяет поведение».

## Частые ошибки

| Ошибка | Симптом | Что объяснить |
|---|---|---|
| `print` вместо `return` | `Фактически: None` | Проверка получает `None`; вернуть значение, а не напечатать |
| `Name` вместо `name` | `NameError` | Python различает регистр |
| Нет отступа | `IndentationError` | Тело функции выровнено |
| Нет `f` | В строке видно `{name}` | F-строка подставляет значение |
| Типографские кавычки | `SyntaxError` | Нужны прямые кавычки |
| Лишняя точка/пробел | Вывод не совпадает | Сравнение строгое, посимвольное |

## Что проверять

1. `python3 run_greeting.py`; код 0.
2. Оба вывода совпадают.
3. `greet("Виктор")` возвращает ожидаемое.
4. `git diff` показывает только `greet.py`.
5. Журнал: два запуска, ожидаемое/фактическое, ошибка, если была.

## Оценка

- Уровень 1: функция работает на двух входах, но журнал неполный или участник не объясняет вход/выход.
- Уровень 2: оба запуска и устная проверка совпадают; diff в границах; журнал связывает вход, выход и проверку.
- Уровень 3: участник объясняет, почему функция обобщает, а не перечисляет два случая, и как обнаружит ошибку в третьем входе.

Критические дефекты: изменён `run_greeting.py`, вывод подменён, запуск не выполнялся, результат не совпадает.
