## Содержание

### 1. Что такое функция в этой задаче

Функция — именованный блок, который получает вход и возвращает результат.

```python
def welcome(city):
    return f"Добро пожаловать в {city}!"
```

- `def` начинает определение;
- `welcome` — имя функции;
- `city` — параметр, то есть вход;
- `return` возвращает строку;
- `f"..."` подставляет значение в текст.

Ключевое различие: `print` показывает текст в терминале, а `return` отдаёт значение тому, кто вызвал функцию. Для L02 функция должна **возвращать** строку. Проверочный файл сам печатает результат.

### 2. Демонстрация 1: рабочая функция

Файл `welcome.py`:

```python
def welcome(city):
    return f"Добро пожаловать в {city}!"
```

Файл `run_welcome.py`:

```python
from welcome import welcome

print(welcome("Москва"))
print(welcome("Казань"))
```

Запуск:

```bash
python3 run_welcome.py
```

Ожидаемый вывод:

```text
Добро пожаловать в Москва!
Добро пожаловать в Казань!
```

Обратите внимание: `welcome.py` ничего не печатает. Печатает `run_welcome.py`.

### 3. Демонстрация 2: ожидаемое и фактическое

Показать таблицу на доске:

| Вход | Ожидалось | Фактически | Совпало? |
|---|---|---|---|
| `"Ada"` | `Привет, Ada!` | | |
| `"Борис"` | `Привет, Борис!` | | |

Запустить проверочный файл, который печатает обе строки и завершается с кодом 1 при расхождении. Объяснить: код возврата 0 — проверка прошла; 1 — есть расхождение. Это ещё не `unittest`; формальные тесты вводятся на L03.

### 4. Демонстрация 3: ошибки

Показать по одному примеру:

```python
def greet(name):
    return f"Привет, {Name}!"
```

`NameError: name 'Name' is not defined` — регистр имени.

```python
def greet(name):
return f"Привет, {name}!"
```

`IndentationError` — тело функции должно быть с отступом.

```python
def greet(name):
    print(f"Привет, {name}!")
```

Функция возвращает `None`, потому что нет `return`; проверочный файл получит `None`, а не строку.

```python
def greet(name):
    return "Привет, {name}!"
```

Пропущена `f` перед строкой; подстановки не будет.

Отдельно предупредить о типографских кавычках `“ ”`, которые могут появиться при копировании из чата. Python ожидает прямые `"` или `'`.

### 5. Запрос агенту

- запустить проверку и показать вывод;

## Вопросы на разбор

1. **Чем `print` отличается от `return`?**  
   Ожидаемые элементы: `print` выводит текст; `return` отдаёт значение вызывающему коду; проверка сравнивает возвращённое значение.

2. **Что означает вход и выход функции `greet`?**  
   Ожидаемые элементы: вход — строка имени; выход — строка приветствия; для `"Ada"` — `"Привет, Ada!"`.

3. **Как вы поняли, что результат верный, а не просто «похожий»?**  
   Ожидаемые элементы: сравнили фактический вывод с ожидаемым; проверили код возврата; записали оба запуска; проверили дополнительное имя.

## Типичные сбои

| Сбой | Признак | Действие |
|---|---|---|
| Нет `return` | `Фактически: None` | Добавить `return`, не менять проверку |
| Опечатка в имени | `NameError` | Прочитать имя в traceback, исправить |
| Лишний отступ | `IndentationError` | Выровнять тело функции |
| Забыта `f` | В выводе `{name}` | Добавить `f` перед строкой |
| Типографские кавычки | `SyntaxError` | Заменить на прямые кавычки |
| Агент изменил проверку | Diff в `run_greeting.py` | Отклонить, вернуть файл, записать |
| Зависимость | Предложен `pip install` | Отклонить: стандартной библиотеки достаточно |

## Проверка и свидетельства

1. В корне каждой рабочей копии: `python3 run_greeting.py`; код возврата 0.
2. Вывод содержит два совпадения.
3. Устно: `greet("Виктор")` возвращает `Привет, Виктор!`; это проверка обобщения, а не третье обязательное задание.
4. Diff показывает изменения только в `greet.py`.
5. Журнал содержит два запуска, ожидаемое/фактическое и один прочитанный traceback, если ошибка была.
