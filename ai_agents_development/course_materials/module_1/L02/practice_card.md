# L02. Практика: минимальный Python

**Аудитория:** участники после L01  
**Предпосылки:** L01 — рабочая копия, Git, границы, терминал  
**Время:** 75 минут  
**Цель:** реализовать функцию `greet`, запустить её на двух входах и записать результат  
**Артефакт:** `greet.py`, два запуска, журнал  
**Оценивание:** [`../shared/practice_rubric.md`](../shared/practice_rubric.md), [`../assessment.md`](../assessment.md)

## Входы и снимок

1. Возьмите рабочие копии L01: `L01-opencode/` и `L01-codex/`.
2. Скопируйте в **корень каждой** копии файлы из [`snapshot/`](snapshot/):
   - `greet.py` — заготовка функции;
   - `run_greeting.py` — проверка двух входов.
3. Не меняйте `run_greeting.py`.

Если копии L01 нет, преподаватель выдаёт эталонный снимок L01. Запишите, что использовали эталон.

## Ограничения

- Менять только `greet.py`.
- Не менять `run_greeting.py`.
- Не добавлять зависимости: достаточно стандартного Python.
- Не выходить за рабочую копию.
- Не использовать секреты и сеть.
- Запрос в обеих средах — дословно одинаковый.

### Шаг 1. Условия — 5 минут

Запишите в журнал: среду, версию, видимую модель/настройки или «недоступно», путь к копии, первичную среду.

### Шаг 2. Запуск агента — по 18 минут

Новый сеанс. Запрос:

```text
В этой рабочей копии есть greet.py с заготовкой и run_greeting.py с двумя проверками.

Запусти python3 run_greeting.py и покажи полный вывод.
```

### Шаг 3. Проверка — 20 минут

В корне копии:

```bash
python3 run_greeting.py
echo "код возврата: $?"
```

Ожидаемый вывод при успехе:

```text
Вход: 'Ada'
Ожидалось: 'Привет, Ada!'
Фактически: 'Привет, Ada!'
Вход: 'Борис'
Ожидалось: 'Привет, Борис!'
Фактически: 'Привет, Борис!'
```

Код возврата — `0`.

Устная проверка обобщения:

```bash
python3 -c "from greet import greet; print(greet('Виктор'))"
```

Ожидается `Привет, Виктор!`. Это проверка того, что функция работает не только на двух зашитых примерах.

## Ожидаемое поведение

- Функция возвращает строку, а проверочный файл её печатает.
- При заготовке `NotImplementedError` проверка завершается ошибкой — это нормальный старт.
- Если агент меняет `run_greeting.py`, вы возвращаете файл и записываете отклонение.
- Если агент предлагает установить пакет, вы отклоняете: задача решается стандартными средствами.
- Если агент печатает внутри `greet`, проверка получит `None`; это ошибка, а не альтернативный стиль.

Уровни 0–3 — в [`../assessment.md`](../assessment.md). Критические дефекты: подмена вывода, изменённая проверка, отсутствие запуска.

## Если что-то пошло не так

- **`NotImplementedError`** — функция ещё не реализована; это старт, а не сбой.
- **`NameError`** — проверьте имя переменной в f-строке.
- **`IndentationError`** — проверьте отступ тела функции.
- **`None`** — в функции нет `return` или стоит `print` вместо `return`.
- **`SyntaxError`** — проверьте кавычки и двоеточие после `def`.
- **Инструмент недоступен** — запишите ошибку; выполните задачу в доступной среде, не выдумывайте вторую попытку.
