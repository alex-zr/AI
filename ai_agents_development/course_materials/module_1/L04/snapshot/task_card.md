# Карточка нового параметра L04

## Что изменить

Добавить функции `greet` необязательный параметр `greeting` со значением по умолчанию `"Привет"`.

## Обязательные поведения

| Вызов | Ожидаемый результат |
|---|---|
| `greet("Ada")` | `Привет, Ada!` |
| `greet("  Ada  ")` | `Привет, Ada!` |
| `greet("Ada Lovelace")` | `Привет, Ada Lovelace!` |
| `greet("Ada", "Здравствуйте")` | `Здравствуйте, Ada!` |
| `greet("  Ada  ", "Здравствуйте")` | `Здравствуйте, Ada!` |

Старые вызовы без второго аргумента должны работать как раньше.

  2. `greet("  Ada  ", "Здравствуйте")` → `Здравствуйте, Ada!`
