# L04. Заметки преподавателя

> МАТЕРИАЛ ПРЕПОДАВАТЕЛЯ. Не выдавать участникам.

## Эталонное решение

```python
def greet(name, greeting="Привет"):
    return f"{greeting}, {name.strip()}!"
```

Здесь нет ветвления: L04 не вводит `if` раньше L18. Новый параметр и удаление пробелов решаются сигнатурой и строковым методом.

Новые тесты:

```python
def test_custom_greeting(self):
    self.assertEqual(greet("Ada", "Здравствуйте"), "Здравствуйте, Ada!")

def test_custom_greeting_with_spaces(self):
    self.assertEqual(greet("  Ada  ", "Здравствуйте"), "Здравствуйте, Ada!")
```

## Ожидаемые результаты

- `verify_l04.py` — `PASS`.
- `git diff` — только `greet.py` и `tests/test_greet.py`.
- Три исходных теста не изменены.
- Обе ветки начинаются от одного коммита.

## Как проверять сравнение

Таблица должна опираться на факты:

| Направление | Что считать |
|---|---|
| A. Границы | Изменены только два файла; нет записи вне области; ручные правки записаны |
| B. Результат | 5 тестов; старые вызовы; новый параметр; пробелы по краям |
| C. Проверки | Команда, вывод, diff, базовый коммит, ручные правки |
| D. Сравнение | Одинаковый снимок/запрос/критерии; порядок; вывод ограничен |

## Частые ошибки

| Ошибка | Симптом | Действие |
|---|---|---|
| Параметр без значения по умолчанию | Старые вызовы падают | Вернуть `greeting="Привет"` |
| Новый параметр не применяется к имени с пробелами | `Привет, Ada!` вместо `Здравствуйте, Ada!` | Исправить возврат |
| Изменён старый тест | Diff в трёх исходных тестах | Вернуть, добавить новые |
| Добавлено больше двух тестов | `verify_l04.py` сообщает о пяти ожидаемых | Оставить ровно пять |
| Ветки от разных коммитов | `git rev-parse HEAD` отличается | Пересоздать от базы |
| Ручная правка не записана | Diff не совпадает с ответом | Восстановить запись |
| Слияние с `--force` | История перезаписана | Недопустимо; остановить и разобрать |

## Ограничения вывода

Даже если одна среда справилась быстрее, нельзя утверждать, что она «лучше вообще». Нужно записать:

- какие модели/настройки были видимы;
- какие разрешения показывала каждая среда;
- сколько времени измерялось и чем;
- какие ручные правки вмешались;
- что не проверялось.

Если модели различались, вывод ограничивается: «в данных условиях, с данными моделями». Если модель не видна, пишется «недоступно».

## Оценка
