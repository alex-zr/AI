# Три обязательных поведения L03

Функция `greet` принимает строку и возвращает строку.

| № | Вход | Ожидаемый результат |
|---|---|---|
| B1 | `greet("Ada")` | `Привет, Ada!` |
| B2 | `greet("  Ada  ")` | `Привет, Ada!` |
| B3 | `greet("Ada Lovelace")` | `Привет, Ada Lovelace!` |

## Границы

- B2: удаляются только пробелы по краям имени; внутренние пробелы не меняются.
- B3: пробел между частями имени сохраняется.
- Другие типы, числа, `None`, списки и дополнительные языки не проверяются.
- Формулировки и ожидаемые строки не меняются.

## Что должно быть в сдаче

- три теста `unittest` в `tests/test_greet.py`;
- один тест на каждое поведение;
- красный запуск до исправления;
- зелёный запуск после;
- минимальный diff в `greet.py`.
