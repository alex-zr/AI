## Эталонное исправление

```python
def greet(name):
    return f"Привет, {name.strip()}!"
```

Здесь нет ветвления: занятие не вводит `if` раньше L18. Все три поведения решаются строковым методом и f-строкой.

## Эталонные тесты

```python
class GreetTest(unittest.TestCase):
    def test_behavior_1_plain_name(self):
        self.assertEqual(greet("Ada"), "Привет, Ada!")

    def test_behavior_2_surrounding_spaces(self):
        self.assertEqual(greet("  Ada  "), "Привет, Ada!")

    def test_behavior_3_inner_space(self):
        self.assertEqual(greet("Ada Lovelace"), "Привет, Ada Lovelace!")
```

## Ожидаемый красный запуск

На baseline:

- B1 проходит;
- B2 падает: фактически `Привет,   Ada  !`;
- B3 проходит: внутренний пробел не является дефектом.

Это нормальный результат. Если падают все три, проверьте тесты и импорт. Если не падает ни один, тест не проверяет B2.

## Ожидаемый зелёный запуск

```text
Ran 3 tests in ...
OK
```

`verify_l03.py` должен выдать `PASS`. Скрипт проверяет ровно три теста, падение на baseline и успех на решении. Он не проверяет минимальность diff — это делает преподаватель.

## Слабые тесты

| Слабость | Как обнаружить |
|---|---|
| Только B1 | Baseline проходит, `verify_l03.py` выдаёт FAIL |
| Только B3 | Baseline проходит: внутренний пробел не ломается |
| `assertTrue(True)` | Не связано с `greet`; baseline проходит |
| Ожидание подставлено под фактический вывод | Сравнить с `BEHAVIORS.md` |

## Частые ошибки

- `ModuleNotFoundError: No module named 'greet'` — запуск не из корня копии.
- `IndentationError` — тело тестового метода без отступа.
- Все тесты падают из-за синтаксиса — читать traceback, а не менять ожидания.
- Агент добавил `pytest` — отклонить: карточка требует `unittest` и стандартную библиотеку.
- Агент добавил `if` или `case` — для этой задачи не требуется; вернуть к минимальному строковому решению.

- Уровень 2: красный и зелёный запуски подтверждены, baseline-проверка проходит, diff в границах.
