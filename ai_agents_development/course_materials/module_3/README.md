# Модуль 3. Context Engineering

Четыре занятия по 150 минут, всего 10 часов. Вход — контракт и журнал из [модуля 2](../module_2/README.md). Цели и тайминг заданы [итоговой программой](../../agentic_development_course_final.md#lessons).

| L10. Объём контекста | Матрица четырёх попыток и сверка требований | [План](L10/lesson_plan.md) · [Практика](L10/practice_card.md) |
