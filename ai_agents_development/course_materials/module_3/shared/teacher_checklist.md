# Подготовка преподавателя

- Проверьте доступы, возможность свежего сеанса, видимость настроек и способ сверки копий.
- Раздавайте карточки, формы и только ученические снимки. Для L10 соберите четыре копии по спискам входов, исключите файлы полного пакета из сокращённых копий. Полный контрольный перечень можно использовать вне агента для оценки, но не переносить в запрос или сокращённую копию. Закрытые ориентиры держите отдельно.
- Для L11 выделите учебный каталог отдельно от правил основного репозитория. Для L12 заранее проверьте режим чтения и отсутствие доступа к другим данным и командам. При необходимости подготовьте маркированные сохранённые ответы или письменную симуляцию.
- Демонстрируйте на другом материале. На приёмке попросите показать фрагмент, который подтверждает одно решение, и назвать границу вывода.
