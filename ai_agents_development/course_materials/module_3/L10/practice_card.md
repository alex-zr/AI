# Практика L10. Объём контекста

Аудитория — участники курса. Предпосылки: L09 — отбор источников, L08 — матрица четырёх попыток.

## Входные файлы

- [task.txt](snapshot/task.txt)
- [brief.md](snapshot/brief.md)
- [requirements.md](snapshot/requirements.md)
- [glossary.md](snapshot/glossary.md)
- [archive.md](snapshot/archive.md)
- [compact.md](snapshot/compact.md)

## Задание

В каждой среде выполните запрос из task.txt с полным пакетом (brief.md, requirements.md, glossary.md, archive.md), затем с сокращённым (brief.md, compact.md), либо в обратном заранее заданном порядке. В чистую копию каждой попытки включите только запрос и файлы соответствующего пакета. Сверьте требования R1–R4 по полному перечню после попыток. При потере исправьте пакет и повторите документарную сверку. Дополнительный запуск возможен в пределах времени проверки.

Следуйте [протоколу](../shared/comparison_protocol.md) и сохраняйте исходный результат отдельно от исправления. Работайте с выданным снимком. Дополнительные записи храните за его пределами.

**Время:** 5 подготовка + 32 четыре попытки по 8 + 28 проверка и исправление + 10 журнал = 75 минут.

**Критерии:** Четыре исхода отражены, контекст меняется при неизменном запросе, каждый фрагмент до 200 слов. Сверены требования во входе и в ответах. Для исправленного пакета приложена повторная сверка.

**Сдача:** Матрица двух пакетов и двух сред, свидетельства по R1–R4 и исправленный пакет при потере. Приложите [журнал](../shared/run_journal.md). [Рубрика](../assessment.md).
