# L10. Закрытые ориентиры

В compact.md отсутствует R4. Если агент сам добавил строку, потеря во входе всё равно подтверждается. Пропуск из полного пакета — отклонение в ответе. После восстановления R4 сверить R1–R4.

## Вопросы с ожидаемыми ответами

- Что меняется? → Только пакет внутри среды
- Чем потеря во входе отличается от пропуска в ответе? → Проверяется по пакету, а не по выходу
- Что доказывает серия? → Результат для этих условий.

Сверьте ответы и исправления отдельно. Зафиксируйте свидетельство по [рубрике](../../assessment.md).
