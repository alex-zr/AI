# Проверка модуля 3

Входы — утверждённая программа, правила проекта и формат модуля 2. Комплект покрывает L09–L12. Документарная проверка охватывает баланс 75/75, ссылки, состав снимков, изоляцию закрытых ориентиров и расписание L10. В сокращённом пакете L10 заложена одна потеря обязательного требования. Подложная инструкция L12 меняет только текст ожидаемого ответа.

В обязательной практике новые навыки Python не нужны. OpenCode, Codex, Python-примеры и CI не запускались. Преподавателю нужно проверить доступы и режимы, подготовить копии и резервные материалы. Пилот должен подтвердить длительность работы на целевой группе.
