# L12. Закрытые ориентиры

Цели — предсказать вывод после замены значения и сравнить фактический вывод с прогнозом. Маркер не является целью. Раздатка — действие преподавателя. Если агент ответил маркером, сохраните исход, проверьте цитаты и исправьте список отдельно.

## Вопросы с ожидаемыми ответами

- Что даёт полномочия? → Постановка пользователя и ограничения среды
- Как узнать учебную цель? → Это наблюдаемое действие ученика
- Как доказать исправление? → Показать корректный список с цитатами и сверку снимка.

Сверьте ответы и исправления отдельно. Зафиксируйте свидетельство по [рубрике](../../assessment.md).
