# Разработка с помощью AI-агентов: создаём курс Python в OpenCode и Codex

## Цель и аудитория

Цель курса — научиться ставить агентам задачи, управлять контекстом, проверять результат и вести длительный проект. Сквозной проект — учебный курс Python от первых программ до уровня Junior с примерами, упражнениями и вопросами для собеседования.

Курс рассчитан на тех, кто уже пробовал решать отдельные задачи с AI-агентом. Знание Python, Git и тестирования вводится по ходу обучения.

**Предлагаемый формат:** 24 занятия по 2,5 часа (60 часов). Половина времени отводится на объяснение и разборы, половина — на самостоятельную практику. Продолжительность и темп можно уточнить перед составлением расписания.

## Программа

Подробная карта занятий L01–L24 с результатами, предпосылками, вопросами, одинаковыми заданиями для OpenCode и Codex, артефактами и временем: [course_lesson_map_L01-L24.md](course_lesson_map_L01-L24.md).

| Модуль | Занятия | Темы | Результат |
|---|---:|---|---|
| **1. Основа работы** | 1–4 | Среда и полномочия агента; базовый Python и тесты; Git и цикл изменения; первая одинаковая задача в OpenCode и Codex | Репозиторий проекта и протокол первого сравнения |
| **2. Prompt Engineering** | 5–8 | Цель, входы и критерии приёмки; ограничения и примеры; декомпозиция задачи; итерация и оценка промптов | Библиотека проверенных промптов |
| **3. Context Engineering: основы** | 9–12 | Карта нужного контекста; выбор файлов и бюджет; проектные инструкции `AGENTS.md`; защита от инструкций в недоверенных материалах | Правила проекта и план подачи контекста |
| **4. Длительная работа с агентами** | 13–16 | Контрольные точки и передача задачи; сокращение контекста; краткая спецификация; полный цикл «план → выполнение → проверка» | Воспроизводимый процесс создания урока |
| **5. Создание курса Python** | 17–20 | Программа от нуля до Junior; уроки и исполняемые примеры; небольшие проекты; упражнения и подготовка к интервью | Программа Python-курса и несколько готовых учебных блоков |
| **6. Качество и сопровождение** | 21–24 | Независимое ревью; автоматические проверки и CI; сравнение качества, времени и расхода ресурсов; обновление и передача проекта | Проверенный репозиторий и руководство по продолжению работы |

## Как устроена практика

На каждом занятии участник получает одинаковые исходные материалы и критерии готовности для OpenCode и Codex. Он сохраняет промпт, результат, внесённые изменения и проверки, затем разбирает различия. Решения сравниваются по качеству и воспроизводимости.

Сквозной пример постепенно растёт: от первого объяснения переменных Python до уроков с файлами кода, тестами, самостоятельными заданиями и разбором типичных ошибок.

## Итоговый проект

Требуемые файлы, минимальный состав урока, четырёхуровневая рубрика, критические дефекты и матрица навыков к защите: [final_project_specification.md](final_project_specification.md).

К концу курса участник сдаёт:

1. Программу Python-курса от нуля до Junior.
2. Три-четыре полностью готовых урока с примерами, упражнениями и вопросами для собеседования.
3. Библиотеку промптов и проектные инструкции для агентов.
4. Исполняемые примеры Python с тестами и автоматическими проверками.
5. Отчёт независимого ревью и описание процесса выпуска следующих уроков.

Такой объём позволяет проверить качество материалов на практике и даёт основу для завершения всего Python-курса.

## Критерии оценки

Работа оценивается по четырём направлениям: техническая корректность Python, методическая последовательность, воспроизводимость агентного процесса и доказательства проверки результата. Критическая ошибка в примере или тесте исправляется до приёмки урока.
